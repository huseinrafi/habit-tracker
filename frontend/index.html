Deployment to AWS (Student) Instructions

Because this application runs entirely client-side (SPA) using vanilla assets and local storage, it is extremely simple and cheap to host on your AWS Academy / Student account. Here are the 2 easiest deployment methods:

Method 1: Amazon S3 (Static Website Hosting)

  1. Log into your AWS Management Console.
  2. Go to Amazon S3 and click Create Bucket (name it e.g. my-habit-tracker-project).
  3. Disable "Block all public access" settings for this bucket to make files viewable.
  4. Under bucket Properties, scroll to the bottom and enable Static website hosting. Set index.html as both index and error document.
  5. Upload the files: index.html, styles.css, app.js, and DESIGN.md directly into the bucket root.
  6. Under bucket Permissions, add a bucket policy to allow public reads: 
    {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::YOUR-BUCKET-NAME/*"
    }
  ]
}
  7. Access your live application via the Amazon S3 website endpoint URL listed in bucket properties!

Method 2: AWS Amplify (Recommended & Automated)

  1. Push these files (index.html, styles.css, app.js, DESIGN.md) to a GitHub, GitLab, or Bitbucket repository.
  2. Go to AWS Amplify in the console.
  3. Click New App > Host web app.
  4. Connect your repository and branch.
  5. AWS Amplify will automatically detect the static HTML and deploy it globally within 2 minutes.
  6. Every time you commit changes to Git, AWS will automatically rebuild and deploy the app!
